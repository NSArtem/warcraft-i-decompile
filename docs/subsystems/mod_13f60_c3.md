# mod_13f60 (area mod_13f60_c3): setup-menu screens

Two-player setup menu and slot helpers in `src/mod_13f60/`.

## Functions

| Addr | Name | Status | Notes |
|---|---|---|---|
| 0x14ad8 | SaveSlotCreate | reference | Runs a slot dialog, then creates a save file and writes a 0x20-byte name, two zero longs and the magic 0x31726157 ("War1"). Mismatch at 0x14aeb: the reference loads `mov esi, 0` where the original has `mov esi, 0x14668`. |
| 0x15244 | ControlTitleDraw | reference | Builds the "system has control" banner and draws it centred (0x140 wide). The reference fails because dat_5165c, dat_51658, dat_5ab8c and dat_5ab9e are unnamed in the DB. |
| 0x15588 | MainMenu | reference | Runs dialog 0x105 and switches on the result to set `setup_state` and `game_start_mode`. Mismatch: dat_5ab9e is unnamed, and the jump-table reloc at 0x155dd differs. |
| 0x15898 | CustomGameMenu | reference | Runs dialog 0x17f, or 0x186 when dat_516ae is set. Mismatch: `xor dl,dl` in the original against `xor ah,ah` in the reference [REG]. |
| 0x1599c | SetArmyScreen | reference | The original has a 4-register prologue (push ebx, push edi). The reference has a 3-register one [regalloc]. |
| 0x15b30 | SetRacesScreen | reference | The original keeps `cur` in bx. The reference keeps it in ax [regalloc]. |

## T3
These files must still match: choose_campaign_dialog, load_game_dialog, play_introduction, select_game_type_dialog, set_irq, set_map_dialog.

## T4
`tests/test_mod_13f60_c3.py` runs each reference function against the original code in the emulator.

- Callees are stubbed, and their register arguments are logged and compared. Stack pointers are never logged.
- Watched globals are compared after each run.
- Symbol addresses come from the symbol DB. Placeholder names (`fn_XXXXX`, `dat_XXXXX`) fall back to the address in the name.
- Buffers are allocated only inside `init_emu`.
- `test_reference_files_still_mismatch` fails if a reference file starts to match. In that case, promote the file to T3.

## Data
- Slot name table at 0x592e8: 7 entries of 0x20 bytes. An empty slot is filled from the string at 0x56b40.
- The words at 0x5ab8c..0x5ab9e hold the preview layer descriptor: flag, x, y, w, h, bitmap pointer, draw callback. 0x5ab9e is the dirty flag.
- `screen_mode` is at 0x593f6. `dat_516ae` is the two-player flag.
