## Data
`palette_cycles`: 16 entries x 12 bytes (0xc0 bytes total).

## Function
The original body is `push ebp; mov ebp,esp; mov ebx,0xc0; xor edx,edx; mov eax,palette_cycles; call memset_; pop ebp; ret`. It is equivalent to `memset(palette_cycles, 0, 0xc0)`.

The reference C (`palette_cycles_clear_reference.c`) does not match. Compiled, it adds push/pop of ebx and edx around the `memset_` call, and the original has no such saves. The original is probably a different frame or a different pragma. The reference is guarded by `assert_ref_mismatch`.
