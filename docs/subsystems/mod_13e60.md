# mod_13e60 – demo / attract-mode sequencer (0x13e60..0x13f60)

Small module that cycles through a table of demo "step" functions.

## Functions
| Addr | Name | Status | Notes |
|---|---|---|---|
| 0x13e60 | DemoIdleTick | T3 match | idle-timer tick |
| 0x13e94 | fn_13e94 / DemoIdleTimerReset | T3 match | resets `demo_idle_timer` |
| 0x13ea0 | DemoStepStartScenario | reference (T4) | sets game_mode=3, scenario from `demo_steps[demo_step_index].scenario`, clears net_play_flag/custom_game, sets screen_mode and own_campaign to 1, returns 1 |
| 0x13ef8 | DemoStepMainMenu | T3 match | |
| 0x13f0c | DemoRun | reference (T4) | sets demo_mode=1, advances step index (wrapping at NULL fn), calls step until a nonzero short result, then `demo_idle_timer = 0x10e` |

## Data
- 0x5152c `demo_mode` (u16), 0x5152e `dialog_modal` (u16)
- 0x51530 `demo_idle_timer` (s16), 0x51532 `demo_step_index` (u16)
- 0x51534 `demo_steps[]`: 6-byte entries `{ int (*fn)(void); short scenario; }`, fn == NULL terminates.

## Reference blockers
Both references differ from the original only in register allocation: DemoStepStartScenario (original 0x13ea1 `push ecx`, compiled `push edx`) and DemoRun (original 0x13f0d `mov dx,[0x51532]`, compiled `mov ax,...`). Behaviour is equivalent.

## Tests
`tests/test_mod_13e60.py`: T3 matches for the three matched files, a near-miss guard for the two reference files, and T4 differential tests (emulator, original vs compiled). DemoRun uses stubs at step-function addresses (no args, logged by address only) with several return-value patterns and start indices. Global addresses for the scenario test are resolved via the symbol DB.
