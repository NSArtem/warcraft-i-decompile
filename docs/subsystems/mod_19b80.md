## Data
- map_bookmarks at 0x50e3e: 3 slots of {short x; short y}.
- Timers: u16 at 0x5951c and 0x5951e. Pending help text pointer at 0x59508. Help text at 0x59500.
- Status bar blit descriptor at 0x5ab7c: x=0x48, y=0xa0, w=0xf0, h=10, bitmap pointer at 0x5ab84, function pointer at 0x5ab88 (BitmapBlitTransparent).
- Mouse x and y at 0x59428 and 0x5942a.
- Handlers: press at 0x59504, release at 0x5950c. Map handlers at 0x59510, 0x59514 and 0x59518.

## Tests
- T3: every matched file is rechecked under its declared compiler.
- Near-miss: the four `*_reference.c` files must still fail to match. The blockers are:
  - BookmarksInit: branch displacement.
  - TimersTick: register allocation.
  - HotkeyDispatch: register allocation.
  - MouseUpdate: an extra push.
- T4: each reference is run in the emulator against the original, with callees stubbed and logged. The compared state is the watched memory and the stub call logs.
