# mod_34060 – DPMI free-memory query

| Addr | Name | Notes |
|---|---|---|
| 0x34060 | DpmiGetFreeMemoryKB | DPMI INT 31h AX=0500h (Get Free Memory Information); returns dword at buf+0x10 (total unlocked pages) * 4 (KB). |

## Evidence
- Calls Watcom runtime `segread` (0x30e57) and `int386x` (0x30e7f) with interrupt 0x31.
- Sets eax=0x500 and edi = pointer to a 48-byte (12 dword) local buffer, with es from segread.
- The return value is read from buffer index 4 (offset 0x10) and scaled by 4. The original uses `shl eax,2`.

## Data layouts
- Local `unsigned long buf[12]`: the DPMI free-memory info structure. Index 4 is total unlocked pages.
- `union REGS` and `struct SREGS` are on the stack.

## T3/T4 notes
- No T3-matching files yet. The reference file is near-miss: the compiler emits `lea eax,[eax*4]` where the original has `shl eax,2` (at 0x3409d).
- The T4 difftest stubs segread and int386x and compares the return value and the call logs. Both stubs are logged. The test is `test_dpmi_get_free_memory_kb`.
