# mod_20a80 – network driver glue (0x20a80..0x20c40)

Thin wrappers around a 6-slot driver vtable at 0x59b90..0x59ba4 (slot 0 declared elsewhere; connect 0x59b94, stop 0x59b98, receive 0x59b9c, send 0x59ba0, drain 0x59ba4).

| Addr | Name | Status |
|---|---|---|
| 0x20a80 | NetDriverSelect | T3 matched |
| 0x20b2c | NetDriverConnectShowCursor | T3 matched |
| 0x20b70 | NetDriverShutdown | T3 matched |
| 0x20ba8 | NetDriverReceiveChecked | reference only; T4 difftest |
| 0x20bd4 | NetDriverSendRepeated | reference only; T4 difftest |
| 0x20c1c | NetDriverDrain | T3 matched |

## Data
- `net_driver_*` function pointers (dword each) at 0x59b94..0x59ba4.
- `net_sync_counter` (unsigned short): extra repeat count for sends.

## Reference functions
- **NetDriverReceiveChecked**: calls the receive slot; if low 16 bits of the result are non-zero and differ from the word at far `buf[2..3]` (`p[1]`), returns 0xffff, else the result. Blocker: prologue register choice (orig `push ecx` at 0x20ba9 vs `push ebp`).
- **NetDriverSendRepeated**: calls the send slot (buf_off, buf_seg, len), then repeats it `net_sync_counter` times (short loop index). Blocker: esi/edi and eax/ebx assignments swapped; same opcodes and instruction count.

## Tests
`tests/test_mod_20a80.py`: T3 match for the four matched files, near-miss guard for both references, and T4 differential tests. T4 stubs the driver slot with a stub at 0x20c1c; the stub is logged (eax, edx, ebx for send) and compared against the original. Buffers are allocated in `init_emu`. The harness does not model segments, so the far pointer is passed as a flat offset plus a dummy selector.
