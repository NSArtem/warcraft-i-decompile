# mod_16390_c4 — near-miss reference functions of the dialog engine / outro

Module `mod_16390` (war.exe 0x16390..0x19020). These three functions have a
`*_reference.c` that is behaviourally equivalent but does not yet byte-match
Watcom 10.0a; they are verified by T4 differential emulation
(`tests/test_mod_16390_c4.py`).

| Function | Addr | Reference file | Blocker |
|---|---|---|---|
| DialogActivateItem | 0x17ce4 | dialog_activate_item_reference.c | codegen: stack slot offset differs at 0x17cf1 (`[esp+0x68]` vs `+0x6c`) |
| DialogRun | 0x180a8 | dialog_run_reference.c | regalloc: orig `sub esp,0x30`, id spilled, edi=x/esi=y/ebx=d |
| OutroPlayFlic | 0x188b4 | outro_play_flic_reference.c | codegen: orig `mov edi,esp` vs `lea edi,[esp+8]` at 0x188d3 |

## Data layouts (src/include/mod_16390.h)
- `Dialog`: layer +0, x +2, y +4, params +6, w +0xa, items +0x26.
- `DialogItem` (0x1c bytes): type +0, flags +2, code +8, text +0x12, id +0x16.
  DialogActivateItem switches on `type`: 0/9 finish with `id`; 1/2 list prev/next;
  6 calls `params[id]`; 7/10 run an edit field on the *following* item (10 also finishes with `code`).
- `Layer` (18 bytes, array at 0x5aa90); outro uses layers 13 and 14.
- Outro state words 0x59430..0x59436 (done, is_orc, frame, tick).

## T3 / T4 notes
- T3: no files are matched in this area yet (`assert_t3_matches(..., [])`).
- Near-miss guard: each reference must still fail to match (`assert_ref_mismatch`).
- T4: every callee is stubbed and logs its register args. Stack pointers
  (local buffers, `hdr`, `saved`) are never logged. Buffers are allocated only in
  `init_emu`. Callee addresses are resolved from the symbol DB by name.
- DialogActivateItem: all item types, edit accepted/cancelled; `ListDraw` takes 1 arg
  (`d` in `eax`); `strcpy` and `EditFieldRun` stubs emulate their effects (`EditFieldRun`
  takes 4 register args + 1 stack arg `maxlen`, popping 4 stack bytes).
- DialogRun: faded/non-faded, screen_mode, auto-update and setup_quit branches;
  original copies the 40-byte `event_handlers` table via inline `rep movsd` while the C
  calls clib `memcpy` (handled by `Emu`'s built-in flat memcpy stub, verified via `watch`).
- OutroPlayFlic: open/rewind failure, orc/human, flic restart, NextFrame failure and
  long human run hitting the sound-trigger frames (0xd, 0x17, 0x1a, 0x37, 0x3f).
  GdsAlloc alternates two buffers. Loop terminates when `layers[13].y + layers[13].h - 1 == 30`.
