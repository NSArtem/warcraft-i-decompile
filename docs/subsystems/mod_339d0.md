# mod_339d0 — palette fade setup

## Functions

| Addr | Name | Notes |
|------|------|-------|
| 0x339d0 | PaletteBeginFade(first, count, target_rgb) | For entries [first, first+count): copies palette_cur into palette_base (snapshot) and copies target_rgb into palette_target. |

## Data

| Addr | Name | Layout |
|------|------|--------|
| 0x5ad60 | palette_base | 768 bytes, 256 RGB entries |
| 0x5b060 | palette_cur | 768 bytes, 256 RGB entries |
| 0x62570 | palette_target | 768 bytes, 256 RGB entries |
