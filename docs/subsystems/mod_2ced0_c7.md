# Unit visibility, map picking, and the simulation tick (`mod_2ced0_c7`)

| Address | Function | Evidence and behavior |
|---|---|---|
| `0x2d650` | `UnitsUpdateVisibility` | `0x2d65e` loads 200; `0x2d66d` sets both low visibility bits before the `0x020d` flags check. For records passing that check, cheat bit 0 clears both bits (`0x2d683–0x2d690`); otherwise the two `FogRectMatchesMask` calls (`0x2d6ac`, `0x2d6d4`) independently clear bits 0 and 1 on a zero low-word result. |
| `0x2df9c` | `MapPickOrderTarget` | `0x2dfa7–0x2dfe1` scales scroll by 16 and applies mouse-origin biases of 72 and 12. `0x2dff4–0x2e019` filters flags `0x020f` and visibility bit 0. Signed viewport clipping (`0x2e032–0x2e073`) precedes inclusive unsigned word hit tests (`0x2e079–0x2e08f`). The first hit selects the cursor through placement, mode, and owner checks (`0x2e091–0x2e0d5`). A miss stores a null target without writing the cursor (`0x2e0eb–0x2e0ed`). |
| `0x2ec0c` | `SimulationTick` | The unit loop skips flag bit 0, handles the `0x0200` gone timer separately, and otherwise decrements the tick timer before context and order processing (`0x2ec2c–0x2ed31`). The `0x1800` state can be cleared before dispatch; a pending `0x0800` after the update becomes `0x1000` (`0x2ec96–0x2ed01`). A zero advance result allows the order callback; a nonzero callback result causes a second advance (`0x2ed03–0x2ed2c`). The object pass precedes `UnitUpdateAll`, `UpdateUnitTimersAndResources`, and `DrawListSort`, called in that order (`0x2ed4b–0x2ed9e`). |

## Data layout

- **Units:** `unit_array` (`0x59640`) points to 200 records, stride `0x5c` (`0x2d658–0x2d665`, `0x2d6e2–0x2d6f3`). Word pixel coordinates are at `+0x00/+0x02` (`0x2e032`, `0x2e055`); the fog coordinate pair starts at `+0x0a` (`0x2d665`, `0x2d6aa`). Visibility is a byte at `+0x0f`; flags are a word at `+0x10` (`0x2d66d`, `0x2d671`). Type, owner, and order are bytes at `+0x1b`, `+0x1e`, and `+0x1f` (`0x2d694`, `0x2ecb1`, `0x2ed16`). Tick timer and gone timer are words at `+0x18` and `+0x4a`; tick context uses bit `0x20` of byte `+0x49` (`0x2ec70`, `0x2ec57`, `0x2ecc3–0x2ecc9`).
- **Size tables and pick output:** The type byte indexes four-byte entries in `unit_type_size` (`0x51abc`, `0x2d694–0x2d69a`) and `unit_pixel_size` (`0x51b9c`, `0x2e01f–0x2e02a`). The latter stores width followed by height; `0x51b9e` is the first height, not a separate table. `map_order_target` (`0x5a7bc`) stores the selected record pointer or null (`0x2e0ed`).
- **Tick context and dispatch:** The current-unit dword at `0x50f7c` is initialized from `unit_array`, advanced in the unit loop, and cleared before the object pass (`0x2ec11–0x2ec16`, `0x2ed31–0x2ed45`). Bytes `0x5a7c6/0x5a7c7` receive the low nibble of the owner-table entry at `0x50012` and the masked unit tick bit (`0x2ecb1–0x2ecc9`). Unit orders index the pointer table at `0x5158c` (`0x2ed14–0x2ed19`). `object_array` (`0x59644`) points to 100 records of stride `0x26`; byte `+1` bit 0 skips processing, `+6` is passed to the gate, and byte `+2` indexes the callback table at `0x511f4` (`0x2ed4b–0x2ed92`). The callback receives the record base.

## Reconstruction status

`unit_finalize_gone.c` is the existing T3 file guarded by the exact-match test. The three references remain T4 near misses: loop-entry branch displacement at `0x2d668` and `0x2dfef`, and loop-counter register selection at `0x2ec1b`. The differential tests compare visibility writes, cursor and target writes, tick state, and ordered callee traces using the original entries unstubbed. These tests were not run here; the difftest links identify the tests to run, not completed verification.
