# mod_1e100 — startup and game-mode dispatch

| Address | Function | Disassembly evidence |
|---|---|---|
| `0x1e100` | `InitNewCampaign` | The campaign-start arm calls it at `0x1e27c`, then joins the write of mode 3 at `0x1e281`. Its body is not included in the dispatch excerpt. |
| `0x1e158` | `RunGameModeLoop` | Called by `__CMain` (`0x3def0`). At `0x1e15e–0x1e18e` it sets the archive version, installs the error-message pointer, clears both save sources, selects mode 8, and initializes input. It refreshes the cursor and screen before dispatching through the jump table at `0x1e12c` (`0x1e198–0x1e1c3`). |

## State layout

- `0x59610` is the 32-bit `slot_file` pointer. `0x59614` is the low word of the dword view whose high word is signed `game_mode` at `0x59616`. At `0x1e235–0x1e23d` the dword is loaded and shifted arithmetically by 16; at `0x1e1ae–0x1e1c3` the mode word is instead range-checked as unsigned before dispatch.
- `pending_save_image` (`0x599b0`, 32-bit) takes precedence over `slot_file` and is cleared when consumed (`0x1e1cb–0x1e1df`). The slot path loads the image, closes and clears the file, and goes back to setup on a null result (`0x1e1e4–0x1e214`). Without either source, `custom_game` (`0x50e4e`, 16-bit) selects the alternate path that sends control packet `0x0d` and checks the mode after ticking (`0x1e216–0x1e252`). Session entry clears `load_not_cancelled` and `evt_pending` (`0x516b0`, `0x516b2`, adjacent words) before the init/run/shutdown calls (`0x1e258–0x1e272`).
- `archive_version` (`0x55824`, 32-bit) receives `0x18`; `archive_version_error` (`0x62890`, 32-bit pointer) receives the address of the message at `0x56f38`, beginning “You do not have the correct data file version.” (`0x1e15e–0x1e168`).
- Splash selects intro or setup from `preferences_load_failed` (`0x52588`, 16-bit; `0x1e340–0x1e35a`). Setup clears `demo_mode` (`0x5152c`, 16-bit; `0x1e2a0–0x1e2ac`). After the end screen, `net_play_flag` and `setup_quit` (`0x52586`, `0x5176a`, 16-bit) can force setup. Otherwise mode 7 advances directly; the other end path copies the word at `0x500ce` to `scenario_number` (`0x50d82`) and uses `0xffff` to distinguish the last scenario (`0x1e2b6–0x1e324`).

## T3 and T4

`tests/test_mod_1e100.py` guards the T3 match for `init_new_campaign.c` and the expected non-match for `run_game_mode_loop_reference.c`. The known reference blocker is a prologue mismatch: the original starts with `push ebx` at `0x1e158`, which the reference build lacks. The T4 test compares watched state and ordered calls across startup, save-source selection, packet aborts, and end-screen transitions. The target is never stubbed; the `exit(0)` callee at `0x33f5c` ends each run from the real dispatch arm at `0x1e369–0x1e36b`. The test has not been executed here.
