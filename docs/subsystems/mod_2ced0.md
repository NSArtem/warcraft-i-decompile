## Data layouts

- **Unit sweep (high):** `unit_array` (`0x59640`) points to `0x5c`-byte records (`0x2d3a3`, `0x2d4a3`). Flags at `+0x10` mask out entire records with `0x207`; nonzero word timers at `+0x36` and `+0x38` decrement (`0x2d3bb–0x2d3eb`). Types 10–14 (`+0x1b`) gain one resource byte (`+0x1a`) unless already `0xff`. When the byte timer at `+0x48` decrements to zero, it reloads to 60 or 40 according to `dat_5008c[unit->player] == 1` (table `0x5008c`, player byte `+0x1e`; `0x2d3ef–0x2d43e`). For other types, a nonzero `dat_51df0[type]` (`0x51df0`) enables decay unless flag `0x400` is set. On expiry, the routine decrements the resource if nonzero; otherwise it subtracts 5 from unsigned health at `+0x16` or calls `UnitRemove` if health is below 5. It rereads the type for the reload after that call (`0x2d440–0x2d4a0`).
- **Drift bytes (high):** `tick_drift_storage` starts at `0x55281`; dword reads at offsets 0 and 1 with `sar eax, 0x18` expose the signed bytes at offsets 3 and 4, which are also the store destinations (`0x2d31b–0x2d39c`). A nonzero low nibble from selector 5 bypasses both the update and the clamps.
- **Fog rectangle (high):** `fog_map` (`0x58578`) points to 16-bit cells with a 64-cell row pitch. Input pointers address pairs of signed shorts `(x, y)` and `(width, height)` (`0x2d5d4–0x2d61a`). Only the tile is masked; the supplied expected word is compared as-is (`0x2d62a–0x2d640`).
- **Perimeter search (high):** Size and target use signed 16-bit halves in EBX and ECX, respectively, with width and target X in the low halves (`0x2e46f–0x2e4b6`). `perimeter_start_direction` (`0x552c8`) is indexed `[y_side][x_side]` (`0x2e4be–0x2e4d4`). `step4_dx`/`step4_dy` (`0x5515c`/`0x55164`) advance or back up the tile cursor (`0x2e556–0x2e57e`); `perimeter_expand_dx`/`perimeter_expand_dy` (`0x552b8`/`0x552c0`) shift the corner after a full lap (`0x2e5a1–0x2e5b8`). The signed width guard at `0x2e4d8–0x2e4e2` stops the search at width 12 or greater before the next lap.

## T3 / T4

No T3 files are listed for this batch. The per-function near-miss guard covers all three reference files: the supplied blockers are a missing initial `push ebx` at `0x2d2e0`, a register allocation difference at `0x2d5d0`, and an extra stack store in the compiled `0x2e464` prologue. The T4 cases compare unit and drift writes plus callee calls, fog return values across row and empty-rectangle cases, and perimeter return values, coordinate writes, and tile-probe order. `UnitRemove` and the two query callees are stubbed, so their internal behavior is outside this coverage. The tests were not run during generation; the pytest nodes are verification hooks, not recorded passes.
