# mod_16390_c5: EditFieldRun (0x17588)

Inline text-entry loop used by the dialog engine (`DialogActivateItem`, 0x17ce4).

| Addr | Name | Notes |
|---|---|---|
| 0x17588 | EditFieldRun | `int (Dialog*, DialogItem*, char *dest, const char *src, unsigned short maxlen)`, watcall; maxlen is the single stack arg, callee pops 4 (`ret 4` at 0x17c49). Returns 1 if the user finished with Enter (0x0d), else 0. |

## Behaviour (from disassembly)
- GdsAlloc(maxlen+1) into `edit_buffer` (0x593e8). If `strcmp(src, str_empty_slot)` (0x56bd8) is 0, the cursor (0x593ec) is 0. Otherwise strcpy and cursor = strlen. The buffer is then space-padded to maxlen and NUL-terminated.
- Rect: x = item.x-3 (+4), y = item.y (+6), right = *(short*)(*(d->cb)) - 1 (d+0x1e), bottom = y + font.rows (cur_font+2) - 1.
- Event source (0x176e6 onward): `net_play_flag` zero means EvtGet; otherwise `screen_mode` selects NetSendLocalEvent or NetQueryRemoteEvent. `setup_quit` aborts with key 0. `dialog_pre_event` is called if set.
- Only type 0x80 key-down events are handled. Numpad scancodes are mapped to the digits '0'..'9' first. The edit keys are:
  - Enter/Esc finishes the loop.
  - Right/Left/Home/End/Del/Backspace move the cursor or delete.
  - Ins (0x5200) toggles insert mode.
  - Printable keys go through `edit_char_hook` (0x5176c). The first typed non-space key clears the field.
- On Enter the buffer is strcpy'd to dest and trailing spaces are trimmed. The buffer is freed with GdsFree.
