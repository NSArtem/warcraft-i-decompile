# Map scrolling input (`mod_25820`)

This module combines mouse-edge requests with directional key input and, on alternating keyboard repeat ticks, mouse-position deltas. The dispatcher chooses the cursor from the **original** edge request, then lets the input helpers change the movement before scrolling the map.

## Functions

| Entry | Symbol | Disassembly evidence |
|---|---|---|
| `0x25820` | `MapScrollAddInputDeltas` | `0x2582e` decrements the word timer and `0x25830` bypasses input unless it reaches zero; `0x2583b` loads the speed-indexed reload. The key groups change `*dy` at `0x2586d`/`0x25898` and `*dx` at `0x258c3`/`0x258ee`. `0x258f1–0x25900` toggles the position phase before the lock and key checks. `0x25920–0x25962` adds `(mouse_x-192)/16` and `(mouse_y-100)/16`, with signed truncation toward zero. |
| `0x25970` | `MapScrollFilterMouseDeltas` | `0x25972–0x25989` clears both deltas and decrements any nonzero timer. At zero, `0x25993` checks repeat before the initial flag at `0x259ad`; either reload preserves the deltas. With neither flag, `0x259c7–0x259ca` clears them. |
| `0x259d8` | `MapScrollApplyDeltas` | `0x259e6–0x25a0c` selects a cursor byte from the incoming deltas or falls back to the low byte of `map_cursor_shape`. `0x25a2a` stores whether either original delta was nonzero. ## Data layout

- `0x5325c`, `0x53266`, `0x53270`: five 16-bit entries each for initial mouse, repeat mouse, and keyboard reloads. The mouse option is a dword at `0x532c0` (`0x2598b`) and the keyboard option is a dword at `0x532c4` (`0x25836`); the loads double the index without a local bounds check.
- `0x5327a`: nine cursor bytes in three rows for edge deltas `-1..1`. The operand at `0x25a00` uses `0x5327b` (element 1) plus `3*(dy+1)+dx`. A zero entry falls back to the low byte at `0x59520` (`0x25a0c`).
- `0x53284`/`0x53286`: keyboard countdown and mouse-position phase words (`0x25823`, `0x25900`, `0x25965`). `0x5a0e0`/`0x5a0e2` are the mouse countdown and raw edge-request words (`0x25972`, `0x25a2a`); `0x5a0e4`/`0x5a0e5` are the initial/repeat flag bytes (`0x259ad`, `0x25993`).
- `0x59428`/`0x5942a`: signed mouse coordinates, extracted from the high words of dword reads starting at `0x59426` and `0x59428` (`0x25920–0x25926`, `0x25944–0x2594a`). `0x59650` gates only the position contribution (`0x25907`); `0x5942e` gates the whole keyboard helper at the dispatcher (`0x25a3b`). The position-key word is at `0x5a936` (`0x25916`); the directional key words are tested in four possibly overlapping groups at `0x25845–0x258ee`.

## Regression coverage

T3 checks the mouse-edge entry and mouse-repeat setter for instruction matches, and guards the four reference files against being mistaken for matches. The recorded near misses include register allocation or instruction form in the input helpers and dispatcher, and the call displacement at `0x25b5e` in the wrapper.

T4 compares the two leaf helpers' delta writes and timer/phase state. Dispatcher tests compare the cursor return, raw edge flag, and ordered calls, using helper stubs that read and rewrite the delta words without logging their stack addresses. Dispatcher cases clear incoming EBX so the full EAX comparison does not depend on the upper half preserved by the original's byte/word operations. Wrapper cases test the full dword passed through `fn_2df9c`, including mutation through its pointer. These are proposed regression checks; no local T3 or T4 run is claimed.
