# Unit footprints and nearby join candidates (`mod_13270`)

These routines update two parallel 64×64 tile maps, check whether a footprint fits, and look for an eligible object near a unit.

| Entry | Function | Behavior and evidence | Confidence |
| --- | --- | --- | --- |
| `0x1379c` | `MarkUnitFootprint` | Called by `UnitCreate` (`0x2e6f4`). Loads width and height at `0x137c0/0x137cb`; ORs the class mask plus `0x0200` into each tile and stores the unit pointer at `0x13821/0x13824`. | high |
| `0x13860` | `ClearUnitFootprint` | Called by `OrderUpdateDeath` (`0x13f68`). Complements the class mask plus `0x0200` at `0x138ca–0x138d5`, then ANDs the tile flags and unconditionally zeroes each object slot at `0x138ec/0x138ef`. | high |
| `0x13990` | `CanPlaceUnitFootprint` | Rejects negative coordinates or an exclusive right/bottom edge above 64 (`0x139b2–0x139e2`). Selects `0x03cc` for types ≤31 and `0x03dc` otherwise (`0x139e9–0x139fa`). Returns 0 on the first masked tile hit (`0x13a39–0x13a51`), or 1 after a clean scan (`0x13a83`). A zero dimension leaves no tiles to test but does not bypass the bounds checks. | high |
| `0x13a90` | `HasJoinCandidateNearby` | Called by `OrderUpdateJoin` (`0x14084`). Starts at `(x−1,y−1)` (`0x13aa0–0x13aa9`) and scans a 3×3 window including the center (`0x13af5–0x13b11`), skipping out-of-map coordinates (`0x13ab6–0x13ac0`). Returns 1 for the first non-null occupant with `(flags & 0x0207) == 0` and class 0 (`0x13acf–0x13af3`), otherwise 0. Writes the loaded `object_map` pointer back at `0x13b15`. | high |

## Data layout

- **Unit prefix:** 16-bit tile coordinates at `+0x0a/+0x0c` (`0x137a6/0x137aa`), 16-bit flags at `+0x10` (`0x13ad6`), byte type at `+0x1b` (`0x137bd`), and byte map class at `+0x1e` (`0x137d5`, `0x13ae8`).
- **`unit_type_size` (`0x51abc`):** width/height word pairs. The height load uses the same four-byte stride from `0x51abe`, the second field of the first pair, not a separate table (`0x137c0/0x137cb`, `0x1399f/0x139a7`). **`unit_map_class_masks` (`0x51dd4`):** word table indexed by map class (`0x137d5–0x137e0`, `0x138c1–0x138d5`).
- **`map_flags` (`0x5857c`) and `object_map` (`0x58580`):** pointer globals, not inline arrays. The footprint code indexes tile `y * 64 + x`, using a two-byte flag word and a four-byte object pointer per tile (`0x137a6–0x137b7`, `0x137e6–0x13808`). Mark and clear assume a valid footprint; they do not clip it (`0x1381c–0x13855`, `0x138e7–0x1391c`).
