# mod_12b80 — BIOS drive fingerprint and DOS block marker

## Functions

| Address | Function | Interface and role |
| --- | --- | --- |
| `0x12b80` | `ComputeBiosDriveFingerprint` | Takes no arguments and returns a 16-bit fingerprint. The module declares separate floppy and hard-drive ID lists at `0x51330` and `0x51333`. |
| `0x12c48` | `CheckDosBlockMarker` | Takes no arguments and returns no value. The module declares the marker tail `OSBLOCK` at `0x512b5` and the diagnostic `CHECK:1` at `0x56a80`. |

## Data layout

| Address | Symbol | Layout and identifying bytes |
| --- | --- | --- |
| `0x512b5` | `dos_block_marker_tail` | `char[8]`: `OSBLOCK` plus NUL. |
| `0x51330` | `bios_floppy_drive_ids` | `unsigned char[3]`: `00 01 ff`. |
| `0x51333` | `bios_hard_drive_ids` | `unsigned char[3]`: `80 81 ff`. |
| `0x56a80` | `dos_block_check_error` | `char[8]`: `CHECK:1` plus NUL. |

The addresses and byte layouts come from the supplied module declarations. Instruction-level details of the fingerprint calculation and the marker failure path are not established here.

## Regression coverage

Both C files are reported as T3 matches. `tests/test_mod_12b80.py::test_t3_matches` checks those matches under each file's declared compiler. There are no reference C files, so this module has no T4 differential test or reference near-miss guard.
